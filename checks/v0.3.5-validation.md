# v0.3.5 release validation — 2026-09-26

## Scope

0.3.5 adds the copy box under every answer (each answer saved in the agent's working folder), `/cli undo`, the
same-file warning, the test gate (detected, on by default; `/cli test`), the shared brief (`/cli brief`), a named
reply for unknown `/cli` words, and stops the ACPX runtime tests leaving temp folders. See the
[changelog](../CHANGELOG.md).

## Evidence

- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`), including
  `checks/test_dev_tools.py` (undo all-or-nothing and its conflicts; the same-file warning from each turn's own
  edit steps, only for overlapping turns; the test gate's detection, one-line commands, off and auto, pass and fail
  with the failure's log first in the copy box; the brief, named in every task and applied in the Codex hook) and
  the copy box in `checks/test_agent_folder.py`.
- **Codex golden record**, re-recorded for the intended Codex changes (170 steps, 35 route kinds): the undo, test
  and brief steps, the help card, the saved answer and its box in relays, and the unknown-word reply. No existing
  step changed its route.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.5.zip` (90 files) and
  `cli-mode-claude-0.3.5.zip` (95 files); both install smokes pass.
- **Live, Claude Code** (`checks/claude_background_live.py --agents grok-build,codex --tools`): every answer was
  saved and ended with its copy box; Grok Build's box, pasted alone into a `/d` to Codex CLI, let Codex read Grok's
  note and return the word only that note held; no answer was posted before its turn's last message.

## Limits

- Undo, the same-file warning, the test gate and the brief are verified offline; the same-file warning relies on
  agents reporting the files their edit steps touch, as ACP tool calls do.
- The Codex host is covered offline (golden record, install smoke).
- The GitHub channels at `v0.3.5` are checked in throwaway configurations after the tag is pushed.
