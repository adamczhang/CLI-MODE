# v0.3.9 release validation — 2026-09-26

## Scope

0.3.9 fixes what a code review of 0.3.8 found and what a full live validation of those fixes on both hosts turned
up: the project brief (text written by hand kept, every conversation's agents listed, one lock, no unwritten host
note with the instant display), approvals (agents that ask first stay unmarked; an approved turn for an agent that
acts without asking allows what its question says; requests of no known kind), `/cli undo` for Copilot and Codex
CLI and in quiet progress mode, and the `/cli usage` helpers. See the [changelog](../CHANGELOG.md).

## Evidence

All live runs used the development build installed in both hosts (Codex from a local marketplace, Claude Code from
the built zip), real agents on their own accounts, and throwaway projects.

- **Readiness:** each agent started through CLI-MODE's controller and answered a one-word task on its default
  model: Antigravity, Claude, Grok Build, Codex CLI and GitHub Copilot. Cursor was signed in but its plan had no
  usage left, so it was not tested.
- **Claude Code, full scenario** (`claude_user_validation.py --depth full`, every extra): 77 turns, all passing.
  The harness now answers Claude Code's own permission questions (`--permission-prompt-tool stdio`), since a hook's
  "ask" is honoured under bypassPermissions.
- **Codex, full scenario** (`codex_user_validation.py --depth full`, every extra, Codex CLI as the second agent):
  67 turns, all passing.
- **Codex, 0.3.6 to 0.3.9 features** (`codex_release_validation.py`, 37 steps each): Grok Build with Antigravity,
  Claude with Antigravity, and Copilot with Codex CLI, all 37 of 37. The Copilot run covers an agent that asks first
  and runs its approved command through ACPX's terminal, and undo of Copilot's edits alone and while Codex CLI edits
  another file in the same turn.
- **Both hosts on one project** (`shared_brief_live.py`, new): 22 of 22 — each host's agent and note in one brief,
  text written by hand kept, approvals with Claude as the agent, `/cli usage` on both hosts, the instant display.
- **Claude Code background turns** (`claude_background_live.py`): one agent, two agents and the tools mode, with
  Grok Build and Antigravity, and with Copilot and Codex CLI.
- **Offline:** the full suite (862 tests) passes; the Codex golden record is unchanged; regression tests fail
  without their fixes (the bridge's `touched` event, undo of edits that name no file, agents that ask first).

## Limits

- Cursor was not run live (its plan had no usage left).
- The Codex Desktop window checks (views, a pasted screenshot, the viewer window) were not run.
- CLI-MODE's own writes to the brief are serialised; the host's note edit, made in its editor, is not under the lock.
- Two agents at once whose edits name no file at all cannot be told apart; `/cli undo` then says so and undoes
  nothing.
