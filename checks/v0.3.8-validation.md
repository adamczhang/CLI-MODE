# v0.3.8 release validation — 2026-09-26

## Scope

0.3.8 adds `/cli usage` (each running agent's plan usage from its own CLI), makes approvals honest for agents that
act without asking (Grok Build), turns a command run without asking into a proper question, and keeps an agent's
paragraphs apart with `/cli progress quiet`. See the [changelog](../CHANGELOG.md).

## Evidence

- **Live, Codex host** ([codex-validation-report.md](codex-validation-report.md)): the shared scenario (67 turns)
  and `checks/codex_release_validation.py` (33 steps: the project brief, approvals, attachments in the desktop app's
  own text, undo and the test gate, a quiet relay). On the released 0.3.7, 24 of 30 steps passed and three real bugs
  were found; with this release's fixes, 33 of 33 passed.
- **Live, `/cli usage`**, across all six agent kinds through the real helpers (no agent started): Claude five-hour
  and weekly windows, Codex CLI's weekly window, Copilot's chat requests left, Antigravity's windows, and "Usage
  reporting not supported through its CLI" for Grok Build and Cursor, in 5.3 s.
- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`), with regression
  tests that fail on 0.3.7 (split paragraphs, a direct command as the question, the honest wording, `approve always`
  refused) and tests for `/cli usage` (report shapes, by name, nobody running, the Codex window names, the Copilot
  account check).
- **Codex golden record**, re-recorded (170 steps, 35 route kinds): only the help card's `/cli usage` row moved.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.8.zip` (92 files: the Codex CLI and Copilot
  usage helpers are new) and `cli-mode-claude-0.3.8.zip` (97 files); both install smokes pass.

## Limits

- Copilot's usage comes from GitHub's undocumented `copilot_internal/user` endpoint; a change there reports
  "can't report its usage" rather than wrong numbers.
- An agent other than Grok is marked as acting without asking only once it is seen doing so.
- The Codex Desktop window checks (views, a pasted screenshot, the viewer window) were not run.
- The GitHub channels at `v0.3.8` are checked in throwaway configurations after the tag is pushed.
