# CLI-MODE 0.3.0 full validation — 2026-09-24

Both hosts (Claude Code and Codex) × six agents, following `cli-mode-validation-plan.md`: offline (Phase 0),
agent layer (Phase 1), Claude Code host (Phase 2), Codex host (Phase 3), install, upgrade and cross-host
(Phase 4). Phase 5 (visual checks in the apps) is a separate checklist. Fixes made during the run are on the
`validation-0.3.0` branch, uncommitted.

## Result

- **Every working agent passes on both hosts after the fixes**: Antigravity, Claude Code, Grok Build and Codex
  CLI, full depth on each host, plus the agent layer.
- **Cursor**: skipped, the account is plan-limited ("Upgrade your plan to continue"); CLI-MODE reports it at
  readiness and leaves nothing active.
- **Copilot**: blocked, an expired user-level `GH_TOKEN` variable overrides Copilot's own `/login`.
- **Matrix**: 535 pass, 26 fixed on the branch and verified again, 2 fail (one cause: the Codex model mangled
  a view reference once), 69 skip. See the end of this file.
- **Offline**: 680 tests pass, no expected failures left; the Codex golden record never moved; both install
  smokes pass.

Environment: Windows 11; Claude Code 2.1.280 (desktop, MSIX), Codex CLI 0.155.1 and the desktop's
0.155.0-alpha.16.4; agy 1.2.9, grok 1.0.41, Copilot CLI 1.0.88, cursor-agent 2026.09.18; Node 26.8.2,
Python 3.14.7, ACPX 0.18.0, PowerShell 7.6.6 and 5.1.

Quota: the live runs used about 5% of a Claude Pro weekly window (5-hour windows peaked at 30%) and about 5% of a Codex Pro weekly window.

## By phase

- **Phase 0 (offline)**: suite, packaging, both install smokes, GitHub installs (`--ref v0.3.0`,
  `@v0.3.0 --sparse`), skill listed only on Codex. New formatting corpus: every event type and content case
  through R1–R3 and the viewer under PowerShell 7 and 5.1; the Codex view checked in a browser at 375 px and
  desktop width, light and dark.
- **Phase 1 (agent layer, controller-driven)**: parity, menus for every model and effort on both hosts,
  settings continuity (warm changes send no readiness prompt, cold recovery exactly one, identity and memory
  kept), controls (access matrix, idle reconnect, native commands, refusals, stop mid-turn), cancel and FIFO
  queues with independent coding acceptance, monitor resume, the live formatting prompt, and the viewer
  window (one per session, closing it mid-turn is safe, reopened next turn, none left after stop; live under
  Windows PowerShell 5.1 too). Agents: agy, grok-build, codex, claude pass; cursor skip; copilot blocked.
- **Phase 2 (Claude Code host)**: the shared 52–60 step scenario at full depth for codex, grok-build, agy and
  claude (all pass after fix 7); extras: reset, long answer in parts, attachment note, viewer through the
  host, formatting prompt ($5 and $10 left as sent, green lines within the guard), compaction mid-relay,
  Stop guard live, and C7 (after fix 8).
- **Phase 3 (Codex host, through `codex app-server`)**: the same scenario at full depth for all four agents,
  then a full rerun on the fixed build: 58/58 including the extras (Full Access gate, formatting, viewer).
- **Phase 4**: upgrade from the released 0.3.0 zip (rebuilt byte-identical from the tag) keeps every saved
  file byte-identical and readable; Grok in Codex and Antigravity in Claude Code at once (separate state,
  simultaneous relays, stopping one leaves the other working).
