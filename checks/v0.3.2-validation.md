# v0.3.2 release validation — 2026-09-24

## Scope

0.3.2 runs several named agents at once on both hosts, sends one prompt to several of them, names agents by
three-letter tags, adds change receipts (`/cli diff`), an adjustable agent timeout and `/cli attach`, removes
Passthrough mode, and on Claude Code runs agent turns as background tasks. See the
[changelog](../CHANGELOG.md).

## Evidence

- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`), including
  new tests for names, several agents, change receipts, timeouts and attach (`test_names.py`,
  `test_agents.py`, `test_changes.py`). The Codex golden record was re-recorded for the intended Codex
  changes (160 steps, 31 route kinds): every existing step keeps its route; the text changes are the names,
  tags, help rows and the removal of Passthrough; new scenarios cover several agents and the agent tools.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.2.zip` (88 files) and
  `cli-mode-claude-0.3.2.zip` (93 files); both install smokes pass in throwaway
  configurations.
- **Live, Claude Code** (headless sessions on the unpacked build, Grok Build and Codex CLI agents):
  - one agent: activation inside the prompt hook, a single background follow labelled with the agent and the
    prompt, the "Passing to" line last, and the answer relayed on the follow's wake-up;
  - two agents: each spawned in the hook, the second while the first worked; each sent a task by name, each
    with its own background row, both answers relayed under their names; closing one kept the other current;
    closing the last turned CLI-MODE off;
  - agent tools, in a git repository: one prompt to both agents (two rows, one "Passing to A and B" line, two
    answers under their names); an edit's receipt with its added and removed line counts in colour; `/cli
    diff`; `/cli timeout 90m`; after the session ended, `/cli attach` in a new session listed both open
    agents, attached one, and it recalled its earlier turn.
- **Live, Codex** (through `codex app-server`, with the plugin installed from this checkout): two agents
  spawned, each sent a task by name, listed, closed one at a time; and the same agent tools scenario, with the
  receipt in the final view.

## Limits

- Cursor, Copilot and Antigravity are verified offline for this release; the live runs used Grok Build and
  Codex CLI.
- The GitHub channels at `v0.3.2` are checked in throwaway configurations after the tag is pushed.
