# v0.3.4 release validation — 2026-09-25

## Scope

0.3.4 gives each agent a working folder (`Agent_Working_Folder/<NAME>/`, git-ignored) for files that are not
project edits, with a saved-files line after each answer and `/cli dir`; fixes lost answers when several agents
finish together on Claude Code; makes the help card compact; and corrects the ACPX install docs. See the
[changelog](../CHANGELOG.md).

## Evidence

- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`, 770 tests),
  including `checks/test_agent_folder.py` (folder, ignore file, listings and their limits, the paragraph sent
  with a task and never with an agent's own slash command, the saved line on both hosts, outside git, a deleted
  `.gitignore`, `/cli dir` by name, tag and short form), the combined relay of agents that finish together
  (`test_agents.py`), the compact help card (`test_help_view.py`), and the live harness's own checks
  (`test_live_harness.py`). The test agents answer with the user's words; the paragraph is checked apart.
- **Codex golden record**, re-recorded for the intended Codex changes (163 steps, 32 route kinds): the new
  `/cli dir` steps, the help card, and one card style rule. No existing step changed its route; the working
  folder itself changes nothing Codex's hooks or controller return.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.4.zip` (89 files) and
  `cli-mode-claude-0.3.4.zip` (94 files); both install smokes pass in throwaway configurations.
- **Live, Claude Code** (`checks/claude_background_live.py --agents grok-build,codex --tools`), in a git
  repository with Grok Build and Codex CLI:
  - asked only to save a research note, with no location given, Grok Build put it in
    `Agent_Working_Folder/<NAME>/`; its saved line came back, it was not counted as a project edit, and
    `git status` never showed the folder;
  - a coding edit by Codex CLI stayed in the project (the only file in its change receipt);
  - two agents given one question: one finished during the turn that relayed the other, and the turn's last
    message carried both answers (an earlier run, before the fix, lost one);
  - `/cli diff`, `/cli timeout`, attach into a new session and close all.

## Limits

- The Codex host is covered offline (golden record, install smoke); no live Codex run was made for this
  release.
- The live harness's check that answers sit in their turn's last message was added after the last live run and
  is covered by its unit tests.
- The GitHub channels at `v0.3.4` are checked in throwaway configurations after the tag is pushed.
