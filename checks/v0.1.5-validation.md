## Limits and release scope

The initial public release uses tag v0.1.5. It was not locally reinstalled. Existing accounts and
installed dependencies were left intact. Full fresh-machine package installation,
Windows elevation, browser OAuth completion, and final Codex popup/menu presentation
have not been live-validated. The wizard reports errors and offers manual setup;
these tests must not be presented as proof of seamless onboarding on every machine.

The popup supports Windows only and needs built-in Windows PowerShell 5.1. Missing
winget, execution-policy blocks and unsupported runtime authentication use manual
fallback. Cancellation is cooperative between package operations; an active package
installer may finish before it stops. A custom ACP launcher is never overwritten
and requires its existing sign-in process. Hook trust and host permissions remain
user-controlled. The GitHub marketplace commands target adamczhang/CLI-MODE at tag v0.1.5.
