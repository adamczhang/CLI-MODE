|---|---|
| Draft model ignored | Transaction snapshots and draft settings drive options; Astra-to-Luna regression verifies Ultra is absent and the selected model/effort is applied. |
| Settings/preflight race | Final locked dispatch admission rejects pending setup; regression opens settings from metadata preflight and verifies no provider prompt starts. |

| Menu state partly prose-driven | Controller owns numbered choices, snapshots, phase transitions and navigation. Stale selections cannot replace a newer menu transaction. |
| Refresh inconsistent | Shared conservative metadata conversion and controller admission; all six capability shapes, failed refresh preservation, successful refresh, and no-session behavior are tested. Legacy Antigravity helper delegates to the controller. |
| Exit/Back ambiguity | Routing says Back; active settings/tuning says Close settings. Active tuning Back returns to Settings, and initial activation Back returns to the previous phase. Shared/backend instructions agree. |
| Returning users treated as new | Any configured backend establishes existing-user status; unconfigured providers are marked Setup needed. Hook/access problems for existing users show Setup needs attention. |
| Diagnostics omit providers | Tool inventory and per-backend probes derive from all registry entries. |

## Limits

These are source, subprocess-fixture and packaged-code checks, not fresh paid
research conversations on every provider. Earlier live observations remain in
the five-CLI and Codex validation reports. Actual Desktop rendering, hook trust,
clean-machine installation and every native terminal command were not newly
certified in this release pass.

Refresh intentionally reads the owned session's last advertised metadata. It
does not reconnect, switch models or launch a second session. Model-specific
effort observations for other models remain cached; new separate-effort models
are withheld until their efforts have been observed. The response reports these
limits instead of presenting cached metadata as a fresh provider connection.
