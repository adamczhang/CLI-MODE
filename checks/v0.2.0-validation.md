# v0.2.0 release validation — 2026-09-23

## Scope

CLI-MODE as a Claude Code plugin alongside the Codex plugin, from one source
tree (the [changelog](../CHANGELOG.md) lists the changes). Evidence comes from
the test suite, install checks in throwaway configurations for both hosts, and
live runs of the installed plugin in the Claude desktop app's own Claude Code
(2.1.280) with the user's real configuration.

## Tests and packages

- **595 tests pass** from source (`python -m pytest checks`), including the
  Codex golden record (138 steps, 29 route kinds). That record was re-recorded
  once, on purpose, for the Agent Settings change (the "5. Done" row removed on
  both hosts); its routes are otherwise unchanged.
- `scripts/package_plugin.py` builds `cli-mode-codex-0.2.0.zip` (84 files) and
  `cli-mode-claude-0.2.0.zip` (88 files); checksums are attached to the Release.
- `checks/claude_install_smoke.py`, in a throwaway `CLAUDE_CONFIG_DIR`, passes for
  both channels: the repository marketplace (as a GitHub install) and the zip's
  `install-claude.ps1`, including an in-place upgrade. Each registers exactly six
  Claude hook handlers and none of Codex's, and answers seven CLI-MODE prompts at
  0 model turns. The zip channel adds the bare `/cli` and `/d` personal commands
  and leaves a user's own `d.md` untouched.
- `checks/codex_install_smoke.py`, in a throwaway `CODEX_HOME`, passes for all six
  agents' installed copies.

## Limits

- Cursor's account returned "Upgrade your plan to continue", so Cursor is
  verified offline on both hosts.
- The final look changes (the colour form that passes the desktop's inline-maths
  limits, and green title rows only) were checked against the desktop app's own
  rendering rules, KaTeX 0.16 and the user's sessions, not by another scripted
  35-turn run. The zero-width space that lets "Passing to …" render while its
  turn is still running (the app keeps a still-streaming block's final "$" as
  text) was checked against the app's parser, not yet seen in the app.
- The GitHub channels (`codex plugin marketplace add … --ref v0.2.0` and
  `claude plugin marketplace add adamczhang/CLI-MODE@v0.2.0`) are checked in
  throwaway configurations after the tag is pushed.
