# v0.1.12 release validation — 2026-09-22

## Scope

This release packages changes after `v0.1.11`: first-session ACPX readiness for
Codex and Claude, measured queue wait ages, new initial model defaults, and the
tabbed `/help` guide. It preserves Direct as the default route and the six-agent
ACPX queue worker. Earlier archives and their historical reports are retained.

## Verification

- Full source test suite: **453 tests passed** in 226.795 seconds.
- Full suite from a fresh extraction of the 0.1.12 archive, empty workspace,
  and isolated Codex home and state: **453 tests passed** in 227.325 seconds.
  The report is at
  `%USERPROFILE%\AppData\Local\Temp\cli-mode-fresh-package-w1rnov8i\evidence.json`.
- The package builder compared all **82 archive entries** with normalized source
  bytes and found six backend registrations.
- The release archive has SHA256
  `cdd0b29ccff2c9b428ae89c495e99567dd32d482350be7988bd22b28821558f9`.
- Python compilation, Node syntax checks for both runtime scripts, and
  `git diff --check` passed during release preparation.
- The preserved v0.1.9, v0.1.10, and v0.1.11 archives retained their recorded
  SHA256 checksums.

The [post-tag live validation](2026-09-22-v0.1.11-live-validation.md) records real
Claude Code, Codex CLI, Grok Build, Antigravity, Cursor, and GitHub Copilot
sequences after the first-session fix. All six completed the home menu and
activation, three queued coding stages, Direct and Passthrough routing, active
cancellation with a waiting follow-up, and owned-session closure. The live
challenge preceded the later model-default and help-page changes; those were
validated separately in the
[defaults and help report](2026-09-22-default-models-validation.md). That report
also records live Codex and Cursor setting probes, a Chrome tabbed-help visual
check, and full source and candidate-package test runs.

Cursor's installed ACP integration does not advertise a High effort selector,
and Copilot advertises neither a model nor an effort selector. A fresh Cursor
Composer 2.5 activation also met the current account's plan limit, though an
earlier separate setting probe accepted the model; no paid upgrade was made.
One Antigravity cancellation attempt timed out under concurrent package-test
load, and a fresh isolated rerun passed. Grok was the speed outlier in the live
challenge, with about five minutes in stage 3 and about 110 seconds before its
first public event.
