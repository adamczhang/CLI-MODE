# v0.1.16 release validation — 2026-09-22

## Scope

A side-by-side audit of the six agents: emissions, provider commands, labels,
menus, per-agent instructions and PowerShell use, with the fixes described in
the [changelog](../CHANGELOG.md).

## Live evidence

`checks/live_parity_probe.py`, run with real accounts on 22 September. Each agent
was activated with `bind`, ran one prompt that reads a file and answers in two
paragraphs, was relayed exactly as the host would, then received an unknown
command, `/model x`, and one advertised read-only command, and was stopped.

| Agent | Activation | Turn | Unknown command | `/model x` | Provider command | Stop |
| --- | --- | --- | --- | --- | --- | --- |
| Antigravity | 44.8 s | 5.5 s | refused | refused | not run (native handoff) | 0.09 s |
| Claude Code | 13.9 s | 8.6 s | refused | refused | `/context`: panel, 2.0 s | clean |
| Codex | 30.4 s | 11.7 s | refused | refused | `/status`: panel, 2.0 s | clean |
| GitHub Copilot | 16.1 s | 4.7 s | refused | refused | `/context`: panel, 1.6 s | clean |
| Grok Build | 12.8 s | 6.0 s | refused | refused | `/context`: ran, no public output | clean |
| Cursor | not verified: "Upgrade your plan to continue" for `composer-2.5` and Auto | | | | | |

Emissions differ by provider and are now handled alike: Claude and Codex send
message IDs; Grok, Copilot and Antigravity do not; Copilot and Claude report usage;
Antigravity's message can arrive before its tool completes. A recorded Grok turn
previously relayed "…two short paragraphs.The file says…"; replayed through the
new grouping, its preamble and answer separate and the final view is the answer.

Antigravity's activation takes about 45 seconds because its ACP server takes about
18 seconds to start and ACPX starts it twice on a new session: once to create the
session over a short-lived connection, and again for the long-lived owner. This is
outside CLI-MODE; an ACPX option to keep the owner after creation would remove it.

Grok Build's setup check once reported it signed out: `grok models` contacts
grok.com, and one call failed. Three later scans passed; the check now retries once.
There is one Grok install (`.grok\bin\grok.exe`, plus the updater's inactive `.old`).

## Limits

Cursor was not verified live. No installed Codex Desktop was used, so the help
card, the relay loop and the tune command were exercised through the controller,
not observed in the app. The live probe consumed a small amount of quota on each
of the five verified accounts.
