# v0.3.1 release validation — 2026-09-24

## Scope

0.3.1 fixes what the [0.3.0 full validation](v0.3.0-full-validation.md) found: CLI-MODE's hooks crashing
under Codex 0.155, which runs Windows hook commands through PowerShell; two Codex menu gaps; the Claude
Code access prompt and settings-page gaps; code fences and escape sequences in relays; and unclear
readiness errors. See the [changelog](../CHANGELOG.md).

## Evidence

- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`),
  including the Codex golden record (unchanged by these fixes), the formatting corpus (every event type and
  content case through the Codex Markdown, the Codex view, the Claude Code text and the viewer window),
  and the hook wrapper test that runs the Windows hook command under cmd.exe, PowerShell 7 and Windows
  PowerShell 5.1.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.1.zip` (86 files) and
  `cli-mode-claude-0.3.1.zip` (91 files); both install smokes pass in throwaway configurations.
- **Live, on the fixed build:**
  - Codex, through `codex app-server`: CLI-MODE's SessionStart and UserPromptSubmit hooks complete under
    Codex 0.155.1 and the desktop's bundled binary (both failed on 0.3.0), and the full scenario passes
    58 of 58 turns with Antigravity, including the Full Access gate, the formatting prompt and the viewer.
  - Claude Code 2.1.280: widening access through `/cli access allow` asks first, and a message typed into
    open settings is reported as not sent.
  - The 0.3.0 full validation's other results (both hosts, four agents at full depth, upgrade and
    cross-host) cover the code this release leaves unchanged.
- **Upgrade paths**, in throwaway configurations, from `v0.3.0` to a newer ref: a tag-pinned GitHub install
  keeps its tag when updated in place on both hosts. Codex moves with `marketplace remove`, `marketplace
  add --ref`, `plugin add`, keeping saved data. Claude Code moves with `plugin uninstall --keep-data`,
  `marketplace remove`, `marketplace add @ref`, `plugin install`, keeping saved data; removing the
  marketplace without `--keep-data` deletes it. The zip's installer updates in place and keeps data.
