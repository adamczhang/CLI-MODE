# v0.3.7 release validation — 2026-09-26

## Scope

0.3.7 makes the project brief (`Agent_Working_Folder/BRIEF.md`) list the agents running now and carry a dated note
from the host written when each agent starts, tells each task which agent it is, and approves only that note's edit
on Claude Code. It also ships the fixes from a code review of 0.3.6 (undo restores only the agent's own edits and
keeps line endings, the test gate's time limit ends the whole run, stale approvals are settled, one-off ACPX clients
for approved turns, fewer transcript reads for pasted images) and removes superseded records. See the
[changelog](../CHANGELOG.md).

## Evidence

- **Offline:** the full suite passes from source (`python -m pytest checks -q -p no:cacheprovider`), with new tests
  for each fix (a runaway test child ended within seconds; a CRLF file restored byte for byte under
  `core.autocrlf=true`; another agent's files left by undo; a queued turn settling an approval; a second `/d`
  neither re-attaching an image nor reading the transcript) and for the brief (its sections, the agent list current
  and empty after close, the kept host note, the Claude note step and its narrow edit approval with every refused
  variant, Codex's rule). Two timing tests (`test_concurrent_updates_are_not_lost`, `UsageOverlap`) can fail under
  heavy load and pass on their own.
- **Codex golden record**, re-recorded (170 steps, 35 route kinds): the short host-note rule in menu turns, the
  `hostNote` activation field and the `/cli brief` wording moved; no step changed its route. Its normalizer masks the
  note's timestamp.
- **Packaging:** `scripts/package_plugin.py` builds `cli-mode-codex-0.3.7.zip` (90 files) and
  `cli-mode-claude-0.3.7.zip` (95 files); both install smokes pass (Claude registers 7 hook handlers, one more for
  the brief's edit).
- **Live, Codex** (app-server, the build installed from the local repository, then restored to v0.3.6): after one
  line of context, `/cli spawn gro` wrote "The user is planning a small garden-planner app. No requirements or
  implementation work have been discussed yet."; the agent was listed and dropped out after `/cli close`.
- **Live, Claude Code** (`checks/claude_background_live.py --agent grok-build`, dev build): the spawn turn read and
  edited the brief with no permission prompt, wrote "Nothing yet, this conversation has just started." and posted the
  activation card last; the `/d`, its background follow, the verbatim relay and the stop all passed. A first run
  found the missing edit approval (the note needed the user's permission), which the release adds.

## Limits

- The note's quality depends on the host model; with `/cli display instant` on Claude Code there is no model turn
  and the entry stays unwritten.
- The review fixes are verified offline; undo's line endings and the test gate's time limit were each reproduced
  failing before the fix and passing after it.
- The GitHub channels at `v0.3.7` are checked in throwaway configurations after the tag is pushed.
