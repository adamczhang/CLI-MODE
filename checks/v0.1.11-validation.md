# v0.1.11 release validation — 2026-09-22

## Scope

This release packages the ACPX runtime hardening, filtered tool/activity
progress, Direct-by-default routing, and a detached FIFO worker for delegated
turns. It starts from `main` at `cffecf7` (v0.1.10). The six CLI backends remain
available. The v0.1.9 and v0.1.10 archives are preserved.

## Verification

- The full source suite passed **440 tests** in 212.747 seconds.
- The full suite passed **440 tests** in 218.475 seconds from a fresh extraction
  of the 0.1.11 archive, empty workspace, and isolated Codex home and state.
  This includes **18 tests through the real pinned ACPX 0.18.0 runtime** with an
  offline fixture agent. Neither run reported skipped tests.
- The first package run exposed a transient Windows state-file sharing conflict.
  State reads and atomic replacements now retry that short-lived conflict;
  persistent failures still surface. Focused regressions cover both sides, and
  the final source and package suites passed.
- The package builder verified all **81 archive entries** against normalized
  source bytes. The suite also verified identical package bytes from LF and
  CRLF source copies and preservation of binary assets.
- Plugin and skill validators passed. Python compilation, Node syntax checks
  for both runtime scripts, and `git diff --check` passed.
- The preserved v0.1.9 archive still has SHA256
  `a5103a42c825e0514e56739e430eb1d70194e84e29be651d4c0023364575f067`;
  v0.1.10 still has SHA256
