# v0.3.0 release validation — 2026-09-24

## Scope

0.3.0 restarts the repository's history with one snapshot: the Codex plugin, its Claude Code port, and
the changes listed in the [changelog](../CHANGELOG.md) (the agent viewer, safer setup, clearer control
states, Claude agent model fixes, and Codex view rendering).

## Evidence

- **634 tests pass** from source (`python -m pytest checks -q -p no:cacheprovider`), including the Codex
  golden record (138 steps), the Claude Code host and hook tests, the package checks and
  `checks/test_agent_docs.py`.
- `scripts/package_plugin.py` builds `cli-mode-codex-0.3.0.zip` (86 files) and
  `cli-mode-claude-0.3.0.zip` (91 files).
- `checks/claude_install_smoke.py` passes in a throwaway `CLAUDE_CONFIG_DIR` for both the repository
  (GitHub) route and the zip's `install-claude.ps1`:
  - `Skills (2)  cli, d`;
  - six Claude hook handlers;
  - eight CLI-MODE prompts answered at 0 model turns;
  - the same slash commands afterwards: `cli`, `d`, `cli-mode:cli` and `cli-mode:d`.
- `checks/codex_install_smoke.py` passes in a throwaway `CODEX_HOME`, with 91 files verified. There,
  `codex debug prompt-input` lists the skill from `codex/skills/cli-mode/SKILL.md`.
- The hook-context size tests include the plugin's own path in the text they measure, so they can exceed
  their budget when the repository sits in an unusually long folder; they pass from a normal checkout.
