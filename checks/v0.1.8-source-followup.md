# CLI-MODE v0.1.8 — source follow-up

> Historical development record. Earlier release tags and archives were retired when v0.1.9 became the initial public release.

Source updated 2026-09-22. This follow-up commit does not replace the existing
published v0.1.8 tag or archive. The earlier v1.0.8 development tag is also retained.

CLI-MODE now supports six persistent agents: Antigravity, Claude Code, Grok Build,
Cursor, GitHub Copilot and Codex CLI. This release includes the six-backend audit
fixes and a shared settings transaction flow.

- Generate one shared activation message for all six providers, using verified settings.
- Display exactly “Usage not available through CLI” when quota cannot be retrieved.
- Keep activation, passing and attribution green; provider reply bodies use normal text.
- Canonicalize provider names and prevent reply text from impersonating activation styling.
- Simplify the README. **368 tests passed** on source and an isolated extracted
  development package for these changes; plugin and skill validation passed.

- Active `/cli mode`, `/cli menu` and `/cli model` (including `$` aliases) open
  Agent Settings. Inactive controls give the explicit activation hint.
- Passthrough remains the default; Direct sends only `/d` or `$d` requests.
- Model-dependent effort menus use draft selections and a stable catalog snapshot.
- Setup opened during prompt preflight prevents dispatch. Empty command updates
  clear stale capabilities. Antigravity selections show the correct current marker.
- Agent lists paginate. Settings fields, navigation, prerequisite probes and
  diagnostics use shared code and validated backend descriptors.
- Numbered choices use persisted transactions. Back/Close in active tuning
  preserves the agent; initial activation keeps its sequential setup flow.
- Refresh reads owned-session metadata without changing models or opening a second
  session. Unavailable refresh retains cached choices with an explicit explanation.

Access remains provider-specific: Claude exposes Allow/Auto-edit/Prompt;
Antigravity, Grok and Copilot expose Allow/Prompt; Cursor and Codex expose Allow only.
Antigravity native commands retain their explicit transport/context handoff.

See the [prior six-backend validation](v1.0.8-validation.md) and the
[original audit](plugin-audit-2026-09-22.md). Historical live tests are not
presented as a fresh six-provider live certification. Desktop hook trust and
account restrictions remain environment-specific. Existing v0.1.8 assets/tag are
preserved. The older [release notes](v0.1.8-release-notes.md) remain available.
